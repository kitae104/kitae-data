MODULE 03 · CLEANING & PREPROCESSING

결측값(NaN) 및 중복 센서 로그 무결성 정제

반도체 센서 통신 일시 지연 등으로 18개의 칸에 NaN(Not a Number)이 검출되었습니다. 결측값을 방치하면 후속 통계 연산 및 머신러닝 학습이 중단되거나 편향이 발생합니다. 따라서 공정 엔지니어링 원칙에 따라 숫자 센서 열은 평균값(Mean)으로 대체하고 중복 수집 행을 소거합니다.

rule 산업 데이터 정제 불문율 2대 가이드라인
  • 정답(타겟 레이블) 열은 절대 fillna 금지: 합격여부를 임의값으로 채우면 정답 신호가 왜곡됩니다. 본 데이터셋은 합격여부 결측 0개로 무결합니다.
  • 중복 제거 후 index 리셋: drop_duplicates() 후 빠진 인덱스 번호를 reset_index(drop=True)로 반드시 0번부터 재정렬합니다.
03_cleaning_pipeline.py 
# 원본 데이터 보호를 위한 Deep Copy
df_filled = df.copy()

# 10대 수치 센서 컬럼 정의
numeric_cols = [
    '온도_섭씨', '압력_Pa', '가스유량_slm', '전력_W',
    '진공도_mTorr', '두께_nm', '습도_pct', '진동_mm_s',
    '처리시간_sec', '냉각수온도_섭씨'
]

# 각 센서별 평균값 일괄 대입
for col in numeric_cols:
    mean_val = df_filled[col].mean()
    df_filled[col] = df_filled[col].fillna(mean_val)

# 중복 행 제거 및 인덱스 번호 리셋
df_clean = df_filled.drop_duplicates().reset_index(drop=True)
print(f"정제 완료! 잔여 결측치: {df_clean.isnull().sum().sum()}개")
