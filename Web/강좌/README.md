# 강좌 폴더

강의 페이지(HTML)와 그 페이지의 탭별 실습 노트북(.ipynb)을 강좌 단위로 묶어 두는 폴더입니다.
`Web/` 아래에 있으므로 Vercel 배포 시 강의 페이지와 노트북이 함께 올라가고, 강의 페이지의
"실습 노트북 받기" 링크로 바로 내려받을 수 있습니다.

## 규칙

- **모든 강의 페이지는 탭형으로 통일합니다. 탭 1개 = 실습 노트북 1개**이고, 탭 번호와 노트북 번호를 같게 맞춥니다.
- 코드가 없는 소개·정리 내용은 별도 탭을 만들지 않고 가까운 탭에 넣습니다(소개 → 첫 탭, 정리 → 마지막 수업 탭).
- 한 탭에 여러 단계가 들어가면 탭 제목 아래에 단계마다 `part-header`(단계 제목)를 둡니다.
  단계가 많아 노트북마다 앞 단계를 반복해야 하는 경우(예: 03 강좌의 9단계)에도 이어지는 단계를 한 탭·한 노트북으로 묶습니다.
- 각 노트북은 혼자 실행되어야 합니다. 다른 노트북에서 만든 변수에 기대지 말고, 필요한 `import`와
  데이터 준비 셀(앞 단계 코드를 모은 "준비" 셀)을 노트북 안에 둡니다.
- 노트북이 읽는 CSV는 `실습/` 폴더에 함께 두고, 강의 페이지에 내려받기 링크를 넣습니다.
- 강의 페이지의 코드 블록 제목(예: `03_dataframe.py`)과 노트북 설명 셀의 `원본 코드:` 값을 같게 두면
  두 자료를 대조하기 쉽습니다.
- 스타일은 공통 파일 두 개만 사용하고 페이지 안에 `<style>`을 두지 않습니다.
  `../../assets/course-tabs.css`(탭 레이아웃·구성요소) → `../../assets/course-design-system.css`(테마) 순서로 연결합니다.

## 새 강좌 추가하기

1. `Web/강좌/04_<강좌명>/`과 그 아래 `실습/` 폴더를 만듭니다.
2. 강의 페이지는 기존 페이지(예: `01_판다스/판다스_수업자료.html`)를 복사해 시작하면 탭·복사 버튼·키보드
   접근성 처리가 그대로 유지됩니다.
3. 탭마다 `실습/NN_<이름>.ipynb`를 만들고, 각 탭의 `session-header` 안에
   `<a class="notebook-link" href="./실습/NN_<이름>.ipynb" download>` 링크를 넣습니다.
4. `Web/order.txt`에 `강좌/04_<강좌명>/<파일명>.html`처럼 **Web 기준 상대 경로**로 추가합니다.
   (적지 않으면 목록 뒤쪽에 가나다순으로 자동 추가됩니다.)
5. `npm run build`로 `Web/index.html`을 다시 만들고, 노트북은 모두 처음부터 실행해 오류가 없는지 확인합니다.
