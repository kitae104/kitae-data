데이터 구조 이해하기 — 인구데이터_4월.csv는 어떤 데이터인가?

남녀가 어떻게 나뉘어 들어 있는지 먼저 살펴봅니다

인구데이터_4월.csv는 행정안전부 주민등록 인구통계 데이터로, 2026년 4월 기준 전국 행정구역별 1세 단위 남녀 인구가 들어 있습니다.
이전 가이드(data1.csv)와 달리 이 파일은 남자와 여자가 분리된 컬럼으로 들어 있어 남녀 비교와 인구 피라미드를 만들기에 가장 알맞은 형태입니다.
항목 내용
측정 시기 2026년 04월
행(row) 수 3,918행 (시도 + 시군구 + 읍면동 전체)
열(column) 수 310열 = 행정구역 1개 + (계·남·여) × 103항목
연령 구간 1세 단위 (0세, 1세, 2세, ..., 99세, 100세 이상)
숫자 형식 "9,298,673" (쉼표 포함! thousands=',' 필요)
컬럼명 패턴 2026년04월_남_30세, 2026년04월_여_30세, 2026년04월_남_100세 이상
파일 인코딩 cp949 (한글 윈도우 기본 인코딩)

📥 인구데이터_4월.csv 다운로드

행정안전부 주민등록 인구통계(2026년 4월)로, 전국 3,918개 행정구역의 남·여 1세 단위 인구(0세~100세 이상)가 담긴 파일입니다. 내려받아 직접 항아리 피라미드를 그려 보세요. cp949 인코딩 · 숫자에 쉼표 포함.

⬇️ CSV 다운로드
🧠

이 파일이 왜 좋은가요?
① 남·여가 따로 들어 있어 인구 피라미드를 그대로 그릴 수 있습니다.
② 1세 단위(0세, 1세, ..., 100세 이상)로 세밀하게 들어 있어, 한 살 한 살을 모두 막대로 그려 "항아리 모양" 인구 피라미드를 만들 수 있습니다.

📂 컬럼 구조 (310열)

행정구역 (1열)
계 (전체) 총인구수, 연령구간인구수, 0세, 1세, ..., 99세, 100세 이상 (103열)
남 총인구수, 연령구간인구수, 0세, 1세, ..., 99세, 100세 이상 (103열)
여 총인구수, 연령구간인구수, 0세, 1세, ..., 99세, 100세 이상 (103열)

합계: 1 + 103 × 3 = 310열

⚠️

실습 전에 꼭 기억할 2가지!
① 숫자에 쉼표가 들어 있음 → pd.read_csv()에서 thousands=',' 옵션을 꼭 넣어야 합니다. 안 넣으면 숫자가 아니라 문자열로 읽혀 계산할 수 없어요.
② 100세 이상 컬럼만 이름이 다릅니다 — 2026년04월_남_99세 다음은 2026년04월_남_100세 이상 (띄어쓰기·"이상" 주의)으로 이어집니다.

파일 읽기 — pandas로 인구데이터_4월.csv 불러오기

thousands 옵션과 인코딩을 동시에 신경 써야 합니다

이 파일은 숫자에 쉼표가 있으므로 thousands=',' 옵션이 필요합니다.
그리고 한글이 깨지지 않게 encoding='cp949'도 함께 지정해야 합니다.
step1_read.py — 파일 불러오기 및 구조 확인 
import pandas as pd

# 인구데이터_4월.csv 불러오기
# 숫자에 쉼표가 있으므로 thousands=',' 필수!
df = pd.read_csv('인구데이터_4월.csv',
                 encoding='cp949',
                 thousands=',')

print(f"행(row) 수 : {df.shape[0]:,}")   # 3,918개
print(f"열(column) 수 : {df.shape[1]}")   # 310개

# 컬럼 이름 일부 확인 — 계/남/여 패턴 보기 (각 시작 위치에서 4개씩)
print("\n[계 컬럼 — 0세~3세]")
print(df.columns[3:7].tolist())
print("\n[남 컬럼 — 0세~3세]")
print(df.columns[106:110].tolist())
print("\n[여 컬럼 — 0세~3세]")
print(df.columns[209:213].tolist())
행(row) 수 : 3,918 열(column) 수 : 310 [계 컬럼 — 0세~3세] ['2026년04월_계_0세', '2026년04월_계_1세', '2026년04월_계_2세', '2026년04월_계_3세'] [남 컬럼 — 0세~3세] ['2026년04월_남_0세', '2026년04월_남_1세', '2026년04월_남_2세', '2026년04월_남_3세'] [여 컬럼 — 0세~3세] ['2026년04월_여_0세', '2026년04월_여_1세', '2026년04월_여_2세', '2026년04월_여_3세']
✅

thousands=','를 넣어주면 "9,298,673" 같은 쉼표 포함 숫자가 자동으로 정수 9298673으로 읽힙니다.
이 옵션을 빠뜨리면 그 컬럼이 문자열(object)로 들어와서 합계·평균을 계산할 수 없어요.

💡

컬럼이 계 → 남 → 여 순서로 묶여 있고, 각 묶음마다 동일한 103개 항목(총인구수·연령구간인구수·0세~99세·100세 이상)이 반복됩니다. '계'를 '남'이나 '여'로 바꾸기만 하면 같은 위치의 다른 성별 컬럼명이 됩니다.

지역 검색 — 읍·면·동까지 세밀하게 찾기

input()으로 입력받아 3,918개 행에서 원하는 지역 찾기

핵심 아이디어: str.contains(findDong)으로 입력한 텍스트가 포함된 행을 모두 찾습니다.
검색 결과가 여러 개일 수 있으니 목록을 먼저 보여주고 번호로 선택하게 합니다. 이 단계는 이전 가이드(data1.csv)와 거의 같습니다.
step2_search.py — 지역 검색 및 목록 출력 
# 검색어 입력
findDong = input("지역 이름을 입력하세요 (예: 역삼, 강남구, 종로): ")

# 입력한 이름이 포함된 모든 행 찾기
matched = df[df['행정구역'].str.contains(findDong, na=False)]

if len(matched) == 0:
    print(f"'{findDong}' 지역을 찾지 못했습니다.")
else:
    print(f"'{findDong}' 검색 결과 ({len(matched)}건):")
    for i, (_, row) in enumerate(matched.iterrows()):
        name = row['행정구역']
        pop  = row['2026년04월_계_총인구수']
        print(f"  [{i}] {name}  →  인구 {pop:,}명")
'역삼' 검색 결과 (2건): [0] 서울특별시 강남구 역삼1동(1168064000) → 인구 34,128명 [1] 서울특별시 강남구 역삼2동(1168065000) → 인구 35,950명
step2b_select.py — 여러 결과 중 하나 선택하기 
# 검색 결과가 여러 개이면 번호를 입력받아 하나를 선택
if len(matched) == 1:
    r = matched.iloc[0]      # 결과 1개면 자동 선택
else:
    idx = int(input("번호를 입력하세요: "))
    r = matched.iloc[idx]

# 선택된 지역 이름 정리 (괄호 앞까지)
region_name = r['행정구역'].split('(')[0].strip()

# 남·여 총인구 미리 확인
print(f"\n선택: {region_name}")
print(f"전체  : {r['2026년04월_계_총인구수']:,}명")
print(f"남자  : {r['2026년04월_남_총인구수']:,}명")
print(f"여자  : {r['2026년04월_여_총인구수']:,}명")

4

남녀 데이터 추출 — 연령대별 두 개의 리스트 만들기

남자 인구 리스트, 여자 인구 리스트를 각각 만듭니다

목표: 같은 길이 101인 두 리스트를 만든다.
male_pop = [남_0세, 남_1세, ..., 남_99세, 남_100세이상]
female_pop = [여_0세, 여_1세, ..., 여_99세, 여_100세이상]
두 리스트를 5단계에서 barh()로 그대로 그리면 한 살 한 살 막대가 쌓여 "항아리 모양" 인구 피라미드가 자연스럽게 만들어집니다.
step3_extract.py — 1세 단위 남·여 인구 리스트 만들기 
# 0세부터 100세 이상까지 라벨 (그래프 Y축에 그대로 쓸 예정)
ages = [str(i) + '세' for i in range(100)]    # ['0세', '1세', ..., '99세']
ages.append('100세 이상')                       # 마지막 한 칸 추가 → 총 101개

# 남·여 인구를 담을 빈 리스트
male_pop   = []
female_pop = []

# 0세부터 99세까지 한 살씩 차곡차곡 담기
for i in range(100):
    male_pop.append(r[f'2026년04월_남_{i}세'])
    female_pop.append(r[f'2026년04월_여_{i}세'])

# 100세 이상은 컬럼명이 다르므로 따로 추가
male_pop.append(r['2026년04월_남_100세 이상'])
female_pop.append(r['2026년04월_여_100세 이상'])

print(f"라벨 개수 : {len(ages)}")
print(f"남자 리스트 : {len(male_pop)}개  → 처음 5개 {male_pop[:5]}")
print(f"여자 리스트 : {len(female_pop)}개  → 처음 5개 {female_pop[:5]}")
print(f"마지막 (100세 이상) : 남 {male_pop[-1]}, 여 {female_pop[-1]}")
라벨 개수 : 101 남자 리스트 : 101개 → 처음 5개 [66, 40, 35, 35, 32] 여자 리스트 : 101개 → 처음 5개 [59, 37, 38, 39, 32] 마지막 (100세 이상) : 남 1, 여 2
✅

f-string의 위력!
f'2026년04월_남_{i}세' 한 줄로 0~99까지 100개의 컬럼명을 자동 생성합니다.
"남"을 "여"로 바꾸기만 하면 여자 컬럼명도 똑같이 만들어지죠. 같은 패턴의 컬럼을 일괄 처리할 때 가장 자주 쓰는 기법입니다.

⚠️

100세 이상은 따로!
2026년04월_남_99세 다음 컬럼은 2026년04월_남_100세 이상입니다 (띄어쓰기 + "이상"). f-string 패턴에서 벗어나므로 반복문이 끝난 뒤 한 줄로 따로 더해줍니다.

📊

이 두 리스트를 barh(ages, male_pop)·barh(ages, female_pop)으로 그리면 — 한 살 한 살 가로 막대가 쌓여 출생부터 100세까지의 인구 분포가 그대로 항아리 모양으로 보입니다. 다음 단계에서 바로 그려 볼게요!

5

그래프 그리기 & 최종 완성

남자는 왼쪽, 여자는 오른쪽 — 항아리 모양 인구 피라미드 완성

0세부터 100세 이상까지 한 살 한 살 모두 가로 막대(barh)로 그립니다. 남자 값을 음수로 바꿔 중앙 기준선의 왼쪽으로 보내면, 여자는 그대로 오른쪽으로 뻗어 나가 자연스럽게 항아리 모양의 인구 피라미드가 만들어집니다.
step4_pyramid.py — 1세 단위 인구 피라미드 (항아리 모양) 
import matplotlib.pyplot as plt
import matplotlib.font_manager as fm
fontprop = fm.FontProperties(fname='malgun.ttf')   # 한글 폰트 파일 직접 지정
import matplotlib as mlp

# 남자 값을 음수로 바꿔 중앙선 왼쪽으로 보내기
male_neg = [-v for v in male_pop]

fig, ax = plt.subplots(figsize=(10, 12))   # 세로로 길게 (101개 막대)

# 같은 Y축(0세~100세 이상)에 가로 막대 두 줄 겹쳐 그리기
ax.barh(ages, male_neg,   color='#3B82F6',
        label='남자', height=0.85)
ax.barh(ages, female_pop, color='#EC4899',
        label='여자', height=0.85)

# 중앙 기준선
ax.axvline(0, color='#1E293B', linewidth=1)

# X축 눈금을 양수로 보이게 (절댓값 라벨)
ticks = ax.get_xticks()
ax.set_xticks(ticks)
ax.set_xticklabels([f'{abs(int(t)):,}' for t in ticks])

# Y축 라벨이 101개라 너무 빽빽 → 10세 간격(0, 10, 20, ...)만 표시
ax.set_yticks(range(0, 101, 10))
ax.set_yticklabels([ages[i] for i in range(0, 101, 10)], fontproperties=fontprop)

ax.set_title(region_name + " 인구 피라미드 (2026년 4월)",
            fontsize=14, fontweight='bold', pad=15, fontproperties=fontprop)
ax.set_xlabel('인구수 (명)', fontproperties=fontprop)
ax.set_ylabel('나이', fontproperties=fontprop)
ax.grid(axis='x', alpha=0.3)
plt.tight_layout()
plt.show()
🔤

한글이 깨지지 않게 — malgun.ttf 폰트 파일을 직접 지정합니다.
fm.FontProperties(fname='malgun.ttf')로 폰트 객체(fontprop)를 만든 뒤, 제목·축 라벨마다 fontproperties=fontprop을 넘겨주면 한글이 정상 출력됩니다. malgun.ttf는 실행하는 .py 파일과 같은 폴더에 두거나, 전체 경로(C:/Windows/Fonts/malgun.ttf)로 적어도 됩니다.

💡

핵심 트릭 3가지
① male_neg = [-v for v in male_pop] — 남자 값을 음수로 바꾸면 막대가 중앙선의 왼쪽으로 뻗어 나갑니다.
② ax.axvline(0) — 0 위치에 세로 기준선을 그어 좌우를 구분합니다.
③ abs(int(t)) — 왼쪽 X축 눈금이 -1000, -500처럼 음수로 나오니, 라벨만 양수로 다시 써줍니다.

🏺

왜 "항아리 모양"이 나올까?
어린아이는 적고(목 부분 좁음), 30~40대가 많고(가운데 불룩함), 다시 노인층은 줄어드는(아래·위 좁음) 인구 분포의 모양이 항아리·종 모양으로 나타납니다. height=0.85로 막대를 살짝 좁혀 살짝의 간격을 주면 더 보기 좋아요.

import pandas as pd
import matplotlib.pyplot as plt
import matplotlib.font_manager as fm

# ① 한글 폰트 설정 (malgun.ttf 파일을 직접 지정)
fontprop = fm.FontProperties(fname='malgun.ttf')

# ② 데이터 불러오기 (숫자에 쉼표 있음 → thousands 옵션 필수!)
df = pd.read_csv('인구데이터_4월.csv',
                 encoding='cp949', thousands=',')

# ③ 지역명 입력 & 검색
findDong = input("지역 이름을 입력하세요 (예: 역삼1동, 강남구, 서울): ")
matched  = df[df['행정구역'].str.contains(findDong, na=False)]

if len(matched) == 0:
    print(f"'{findDong}' 지역을 찾지 못했습니다.")

else:
    # ④ 결과가 여러 개이면 목록 출력 후 선택
    if len(matched) > 1:
        print(f"'{findDong}' 검색 결과 ({len(matched)}건):")
        for i, (_, row) in enumerate(matched.iterrows()):
            name = row['행정구역']
            pop_total = row['2026년04월_계_총인구수']
            print(f"  [{i}] {name}  ({pop_total:,}명)")
        idx = int(input("번호를 선택하세요: "))
        r = matched.iloc[idx]
    else:
        r = matched.iloc[0]

    # ⑤ 지역명 정리
    region_name = r['행정구역'].split('(')[0].strip()

    # ⑥ 1세 단위로 남·여 인구 리스트 만들기 (101개)
    ages = [str(i) + '세' for i in range(100)]
    ages.append('100세 이상')

    male_pop, female_pop = [], []
    for i in range(100):
        male_pop.append(r[f'2026년04월_남_{i}세'])
        female_pop.append(r[f'2026년04월_여_{i}세'])
    male_pop.append(r['2026년04월_남_100세 이상'])
    female_pop.append(r['2026년04월_여_100세 이상'])

    # ⑦ 인구 피라미드 (항아리 모양)
    male_neg = [-v for v in male_pop]

    fig, ax = plt.subplots(figsize=(10, 12))
    ax.barh(ages, male_neg,   color='#3B82F6',
            label='남자', height=0.85)
    ax.barh(ages, female_pop, color='#EC4899',
            label='여자', height=0.85)
    ax.axvline(0, color='#1E293B', linewidth=1)

    # X축 음수 → 양수 라벨
    ticks = ax.get_xticks()
    ax.set_xticks(ticks)
    ax.set_xticklabels([f'{abs(int(t)):,}' for t in ticks])

    # Y축은 10세 간격만 표시 (101개 다 표시하면 빽빽)
    ax.set_yticks(range(0, 101, 10))
    ax.set_yticklabels([ages[i] for i in range(0, 101, 10)], fontproperties=fontprop)

    ax.set_title(region_name + " 인구 피라미드 (2026년 4월)",
                fontsize=14, fontweight='bold', pad=15, fontproperties=fontprop)
    ax.set_xlabel('인구수 (명)', fontproperties=fontprop)
    ax.set_ylabel('나이', fontproperties=fontprop)
    ax.grid(axis='x', alpha=0.3)
    plt.tight_layout()
    plt.show()

📚 이번 프로젝트 핵심 정리

encoding='cp949'

한글 CSV 파일을 깨지지 않게 읽기

str.contains()

3,918개 행에서 이름 포함 검색

f'2026년04월_남_{i}세'

f-string으로 0~99세 컬럼명 일괄 생성

'_100세 이상'

마지막 컬럼만 이름이 달라 따로 처리

ax.barh(ages, values)

1세 단위 101개를 가로 막대로 그리기

[-v for v in lst]

남자 값을 음수로 바꿔 피라미드 왼쪽으로

ax.axvline(0)

피라미드의 중앙 기준선

ax.set_yticks(range(0,101,10))

101개 라벨 중 10세 간격만 표시

abs(int(t))

X축 눈금을 다시 양수 라벨로 표시
