1데이터 분석이란 무엇일까요?

데이터 분석은 한 마디로 "쌓여있는 숫자에서 의미 있는 패턴이나 답을 찾아내는 과정"입니다. 숫자 표가 잔뜩 있어도 그냥 보면 어지러울 뿐이죠. 그 표 안에 숨어 있는 "어, 이게 좀 이상한데?"나 "오, 여기에 규칙이 있네!"를 찾아내는 것이 분석가의 일입니다.

🧩

분석은 퍼즐 맞추기와 비슷합니다. 흩어진 조각(숫자)을 하나하나 살펴보고, 비슷한 것끼리 묶고, 그림(패턴)을 찾는 과정이에요. 처음에는 막막해도 한 조각씩 맞춰 가면 그림이 보입니다.

1CSV 파일 읽어서 DataFrame 만들기

CSV는 "Comma Separated Values" — 쉼표로 구분된 값들이 든 텍스트 파일입니다. 엑셀로도 열 수 있는 가장 일반적인 데이터 파일 형식이에요. pd.read_csv() 한 줄이면 표로 바뀝니다.

📦

DataFrame = 엑셀 시트 한 장이라고 생각하세요. 행은 측정 기록 한 줄, 열은 측정 항목 한 가지입니다. pd.read_csv('파일.csv')는 "이 파일을 표로 읽어줘!"라는 명령입니다.

02_read_csv.py 
# 📂 CSV 파일을 읽어서 df라는 이름의 DataFrame으로 저장

# 데이터 크기 확인: (행의 수, 열의 수)
print(f"데이터 크기: {df.shape[0]}행 × {df.shape[1]}열")

3원하는 "열(컬럼)"만 골라 보기

12개 열을 한꺼번에 보면 어지러우니, 보고 싶은 열만 골라 뽑는 방법을 익혀봅시다. 이때 핵심은 대괄호 [ ] 안에 열 이름을 따옴표로 묶어 적는다는 것입니다.

04_select_columns.py 
## 한 개 열만 선택 → 결과는 Series (열 하나짜리)
df['온도_섭씨']            # 온도_섭씨 한 줄만 200개

## 여러 열 선택 → 결과는 DataFrame (대괄호 두 겹!)
df[['온도_섭씨', '압력_Pa', '합격여부']]

## 한 개 열의 통계 계산
print(f"평균 온도: {df['온도_섭씨'].mean():.2f}°C")
print(f"최고 온도: {df['온도_섭씨'].max():.2f}°C")
print(f"최저 온도: {df['온도_섭씨'].min():.2f}°C")
❗
대괄호 한 겹 vs 두 겹의 차이 • df['온도_섭씨'] → 1차원 Series (한 줄)
• df[['온도_섭씨']] → 2차원 DataFrame (한 열 짜리 표)
여러 개 열을 한꺼번에 뽑을 때는 반드시 대괄호 두 겹을 써야 합니다!

4원하는 "행"만 골라 보기 — loc vs iloc

이번에는 가로줄(행)을 골라내는 방법입니다. pandas에는 두 가지 방식이 있어요. loc은 이름(인덱스 라벨)으로, iloc은 위치(번호)로 찾습니다.

🔍

loc = "이름으로 찾기" — 「김민준 학생 어디 있어?」
iloc = "번호로 찾기" — 「3번 자리 학생!」 (i는 integer = 정수의 약자)

05_loc_iloc.py 
## iloc - 위치(번호)로 선택. 0부터 시작!
df.iloc[0]          # 첫 번째 행 (가장 위 한 줄)
df.iloc[1:5]       # 1~4번 행 (5번 미포함!)
df.iloc[0:3, 0:4]  # 0~2행, 0~3열 (왼쪽 위 모서리)

## loc - 인덱스 이름(라벨)으로 선택
df.loc[0]              # 인덱스가 0인 행
df.loc[0:4]            # 0~4번 행 (loc은 끝 번호 포함!)
df.loc[0:4, ['온도_섭씨', '합격여부']]  # 행+열 동시 지정
⚠️
iloc과 loc의 슬라이싱 차이 — 이걸 자주 헷갈립니다! • df.iloc[1:5] → 1, 2, 3, 4번 (5번 미포함, 파이썬 일반 규칙)
• df.loc[1:5] → 1, 2, 3, 4, 5번 (5번 포함! loc은 양쪽 다 포함)
"loc은 라벨이라 끝까지 포함, iloc은 정수라 끝 미포함"이라고 외워두세요.

5카테고리 값 세기 — value_counts()

"합격이 몇 개, 불합격이 몇 개?" 같이 같은 값이 몇 번 나오는지 셀 때 쓰는 함수가 value_counts()입니다. 데이터의 분포를 빠르게 파악할 때 가장 자주 쓰는 함수 중 하나예요.

06_value_counts.py 
# 합격여부 컬럼의 값별 개수
print(df['합격여부'].value_counts())

# 비율(%)로 보고 싶다면 normalize=True
print(df['합격여부'].value_counts(normalize=True) * 100)

3단계 · 결측값 & 중복 처리 ⏱ 35분
비어 있는 칸과 똑같이 들어간 행을 깔끔하게 정리합니다

🎯 학습 목표

  • ✓결측값(NaN)이 무엇인지, 왜 처리해야 하는지 안다
  • ✓isnull(), sum()으로 결측값 개수를 셀 수 있다
  • ✓fillna()로 평균·중앙값을 채우거나 dropna()로 삭제할 수 있다
  • ✓duplicated()로 중복 행을 찾고 drop_duplicates()로 제거할 수 있다

1결측값(NaN)이 뭐예요?

데이터의 어떤 칸이 비어 있는 상태를 결측값이라고 부릅니다. pandas는 이걸 NaN (Not a Number)으로 표시해요. 반도체 공정에서는 센서가 잠깐 꺼지거나, 측정값을 기록 못 하면 그 칸이 비게 됩니다.

🕳️

결측값이 그대로 있으면 평균·표준편차 같은 계산이 깨지거나 그래프가 이상하게 그려져요. 분석 전에 반드시 채우거나 지워야 합니다. 마치 요리하기 전에 빠진 재료를 챙기는 것과 같아요.

2결측값 찾기

isnull()은 각 칸이 비어 있는지 True/False로 알려주고, 거기에 sum()을 붙이면 열별 결측값 개수가 나옵니다.

07_check_missing.py 
# ① 각 칸이 결측인지 True/False (200행 × 12열의 True/False 표)
df.isnull().head()

# ② 열별 결측값 개수 (True를 1로 세어줌)
print(df.isnull().sum())

# ③ 전체 결측값 개수 (모든 열을 합산)
print(f"전체 결측값 개수: {df.isnull().sum().sum()}개")

# ④ 결측값 비율(%) 보기
missing_pct = (df.isnull().sum() / len(df) * 100).round(2)
print(missing_pct)
📤 예상 출력 예시 측정시간 0 온도_섭씨 7 압력_Pa 6 가스유량_slm 5 전력_W 7 ... 합격여부 0
📌
합격여부에 결측이 0이라 다행! 예측 대상(타겟) 컬럼인 합격여부에 빈 값이 있으면 골치 아픕니다. 다행히 이 데이터는 합격여부가 모두 채워져 있어요.

3결측값 처리하는 3가지 방법

방법코드언제 쓰나요?
평균으로 채우기df['col'].fillna(df['col'].mean())값이 비교적 고르게 분포할 때
중앙값으로 채우기df['col'].fillna(df['col'].median())이상치(튀는 값)가 많을 때
행 통째로 삭제df.dropna()결측이 매우 적을 때 (전체 5% 미만 정도)
08_fill_missing.py 
# 방법 1: 평균으로 채우기 (가장 일반적)
df_filled = df.copy()   # 원본 보호를 위해 복사

# 숫자 컬럼만 골라서 평균으로 채우기
numeric_cols = ['온도_섭씨', '압력_Pa', '가스유량_slm', '전력_W',
                '진공도_mTorr', '두께_nm', '습도_pct', '진동_mm_s',
                '처리시간_sec', '냉각수온도_섭씨']

for col in numeric_cols:
    mean_val = df_filled[col].mean()
    df_filled[col] = df_filled[col].fillna(mean_val)

# 처리 후 결측 확인
print(f"처리 후 남은 결측값: {df_filled.isnull().sum().sum()}개")

# 방법 2: 결측 있는 행 통째로 삭제
df_dropped = df.dropna()
print(f"삭제 전: {len(df)}행 → 삭제 후: {len(df_dropped)}행")
⚠️
합격여부(타겟)에는 절대 fillna()하지 마세요! 예측해야 할 정답을 임의로 채우면 분석 결과 자체가 오염됩니다. 다행히 이 데이터는 합격여부에 결측이 없으니 안심하세요.

4중복된 행 찾고 제거하기

같은 측정 기록이 실수로 두 번 들어가는 경우가 종종 있어요. (CSV 머지, 복붙 실수 등) duplicated()로 중복 여부를 확인하고, drop_duplicates()로 제거합니다.

09_duplicates.py 
# ① 중복된 행 개수 확인
print(f"중복 행 수: {df_filled.duplicated().sum()}개")

# ② 실제로 어느 행이 중복인지 확인
duplicate_rows = df_filled[df_filled.duplicated()]
print(duplicate_rows)

# ③ 중복 제거
df_clean = df_filled.drop_duplicates()

# ④ 인덱스 다시 매기기 (중복 제거 후 번호가 띄엄띄엄 됨)
df_clean = df_clean.reset_index(drop=True)

print(f"정리 전: {len(df_filled)}행 → 정리 후: {len(df_clean)}행")
💡
reset_index(drop=True)는 왜 필요해요? 중복 행을 지우면 인덱스 번호가 (0, 1, 2, 4, 5, 7...) 처럼 빠진 자리가 생겨요. reset_index(drop=True)로 다시 0부터 차곡차곡 매겨주면 보기 좋고 다루기도 편합니다.

4단계 · 탐색적 데이터 분석 (EDA) ⏱ 55분
합격과 불합격은 센서값에서 어떻게 다른지 본격적으로 파헤칩니다

🎯 학습 목표

  • ✓새 컬럼을 추가하고 조건으로 행을 필터링할 수 있다
  • ✓groupby()로 합격/불합격별 평균을 비교할 수 있다
  • ✓히스토그램·박스플롯·산점도·파이차트·히트맵을 그릴 수 있다
  • ✓시각화에서 인사이트(분석 결론)를 끌어낼 수 있다
🧭
EDA(Exploratory Data Analysis)란? "탐색적 데이터 분석"이라고 부르고, 데이터를 이리저리 들여다보면서 패턴·이상 징후·의외의 사실을 발견하는 과정입니다. 요리에 비유하면, 본격 요리 전에 재료를 만져보고 맛보고 냄새 맡아보는 단계예요.

1분석에 필요한 새 컬럼 만들기

원본 데이터에 없는 정보가 필요하면 계산해서 새 컬럼을 추가할 수 있습니다. 컬럼 추가는 매우 간단해요.

10_new_columns.py 
# df_clean을 앞으로 계속 사용 (결측·중복 처리된 깨끗한 표)

# ① 합격여부 1/-1 → '합격'/'불합격' 문자열로 바꿔 보기 좋게
df_clean['result'] = df_clean['합격여부'].map({1: '합격', -1: '불합격'})

# ② 두께가 정상 범위(95~105nm) 안에 있는지 표시
df_clean['thickness_ok'] = (df_clean['두께_nm'] >= 95) & (df_clean['두께_nm'] <= 105)

# ③ 전력 효율 = 두께 / 전력 (전력당 만들어진 두께)
df_clean['power_eff'] = (df_clean['두께_nm'] / df_clean['전력_W']).round(5)

# 결과 확인
df_clean[['온도_섭씨', '두께_nm', 'result', 'thickness_ok', 'power_eff']].head()
💡
map()이라는 함수 map({1: '합격', -1: '불합격'})는 "1을 만나면 '합격'으로, -1을 만나면 '불합격'으로 바꿔라"라는 뜻입니다. 숫자 라벨을 사람이 알아보기 쉬운 글자로 바꿀 때 유용해요.

2조건에 맞는 행만 골라내기

특정 조건(예: "불합격인 행만", "온도가 305 이상인 행만")에 맞는 데이터만 따로 보고 싶을 때 씁니다.

11_filter.py 
# ① 불합격 데이터만 골라내기
fail_df = df_clean[df_clean['합격여부'] == -1]
print(f"불합격 건수: {len(fail_df)}건")

# ② 온도가 305도를 넘는 공정
high_temp_df = df_clean[df_clean['온도_섭씨'] > 305]
print(f"고온 공정 수: {len(high_temp_df)}건")
print(f"그중 불합격: {(high_temp_df['합격여부'] == -1).sum()}건")

# ③ 여러 조건 동시에 (AND는 &, OR은 |, 괄호 필수!)
condition = (df_clean['온도_섭씨'] > 305) & (df_clean['두께_nm'] > 103)
risk_df = df_clean[condition]
print(f"고온+두꺼움 공정: {len(risk_df)}건")

# ④ 특정 값들 중 하나에 해당 (isin)
pass_df = df_clean[df_clean['result'].isin(['합격'])]
print(f"합격 데이터: {len(pass_df)}건")

# ⑤ 정렬: 두께 큰 순으로 상위 10개
df_clean.sort_values('두께_nm', ascending=False).head(10)
❗
여러 조건은 반드시 괄호로 묶으세요 (A) & (B) 처럼 각 조건을 괄호로 감싸야 합니다. 안 그러면 우선순위 때문에 에러가 나거나 엉뚱한 결과가 나와요. 그리고 AND는 &, OR은 |를 씁니다 (파이썬 기본 and/or가 아님!).

3groupby — 그룹별로 통계 내기

이제 본격적으로 분석에 들어갑니다! 우리의 핵심 질문은 "합격 공정과 불합격 공정은 센서값에서 어떻게 다른가?"입니다. 이걸 한 줄로 답해주는 강력한 함수가 groupby()예요.

📊

groupby = 엑셀의 피벗 테이블이라고 생각하세요. "합격 그룹과 불합격 그룹으로 나눠서, 각 그룹의 평균 온도가 얼마인지" 한 번에 계산해 줍니다.

12_groupby.py 
# ① 합격여부별 모든 컬럼의 평균
numeric_cols = ['온도_섭씨', '압력_Pa', '가스유량_slm', '전력_W',
                '진공도_mTorr', '두께_nm', '습도_pct', '진동_mm_s',
                '처리시간_sec', '냉각수온도_섭씨']

group_mean = df_clean.groupby('result')[numeric_cols].mean().round(2)
print(group_mean.T)   # .T 는 행·열 뒤집기 (보기 편하게)

# ② 그룹별 개수
print(df_clean.groupby('result').size())

# ③ 여러 통계를 한 번에 (agg 활용)
df_clean.groupby('result')['온도_섭씨'].agg(['mean', 'std', 'min', 'max']).round(2)

🔍
여기서 발견할 수 있는 사실! • 불합격 공정은 평균 온도가 약 3°C 더 높음 (303.8 vs 300.4)
• 두께도 약 4.6nm 더 두꺼움 (104.6 vs 100.0)
• 진공도도 차이가 있음 (5.46 vs 4.99)
→ 즉, "고온·두꺼운 박막·낮은 진공도"가 불합격의 패턴일 가능성이 큽니다!

6박스플롯 — 합격 vs 불합격 한눈에 비교

박스플롯은 데이터 분포(중앙값·사분위수·이상치)를 상자 모양으로 요약해 보여줍니다. 두 그룹을 나란히 놓으면 차이가 즉시 보여요.

📦
박스플롯 읽는 법 • 상자 가운데 선 = 중앙값(50%)
• 상자 = 데이터의 중간 50%가 들어있는 범위
• 수염(위·아래 줄) = 대부분의 데이터 범위
• 점 = 이상치(outlier) — 평소와 다른 값

한눈에 보이는 차이 불합격 그룹의 상자 전체가 합격 그룹보다 위쪽에 있죠? 이것이 "불합격은 평균 온도가 높다"는 사실의 시각적 증거입니다. 두께도 비슷한 패턴이 나타날 거예요.

7산점도 — 두 변수의 관계 보기

두 변수가 같이 움직이는지(상관관계) 볼 때 쓰는 그래프입니다. 점들이 우상향으로 모이면 같이 커지는 관계예요.

15_scatter.py 
# 온도 vs 두께 산점도, 합격/불합격에 따라 색 다르게
plt.figure(figsize=(8, 6))
sns.scatterplot(data=df_clean,
                x='온도_섭씨', y='두께_nm',
                hue='result',               # 색을 result별로 다르게
                palette=['#52B788', '#E76F51'],
                s=80, alpha=0.7)         # s=점 크기, alpha=투명도

plt.title('온도 vs 두께 (판정별)')
plt.xlabel('온도 (°C)')
plt.ylabel('두께 (nm)')
plt.grid(True, alpha=0.3)
plt.show()
🎨
hue가 뭐예요? "색깔"이라는 뜻의 단어로, seaborn에서 hue='컬럼명'이라고 적으면 그 컬럼 값에 따라 점 색깔을 자동으로 다르게 그려줍니다. 합격은 초록, 불합격은 주황이 되는 식이에요.

8파이 차트 — 합격/불합격 비율 한눈에

전체에서 각 항목이 차지하는 비율을 보여주는 동그란 차트입니다.

16_pie.py 
# 합격/불합격 비율
result_counts = df_clean['result'].value_counts()

plt.figure(figsize=(6, 6))
plt.pie(result_counts.values,
        labels=result_counts.index,
        autopct='%1.1f%%',           # 퍼센트 자동 표시
        colors=['#52B788', '#E76F51'],
        explode=[0, 0.08],            # 불합격을 살짝 떨어뜨려 강조
        startangle=90)

plt.title('전체 공정 합격/불합격 비율')
plt.show()
📊 예상 그래프 모양

9상관관계 히트맵 — 변수들 간의 관계

12개 변수가 서로 얼마나 관련 있는지 한 번에 보여주는 표입니다. 색이 진할수록 강한 관계, 빨간색은 음의 관계, 초록색은 양의 관계예요.

17_heatmap.py 
# 숫자 컬럼만 골라 상관관계 계산
target_cols = numeric_cols + ['합격여부']
corr_matrix = df_clean[target_cols].corr()

# 히트맵 그리기
plt.figure(figsize=(11, 9))
sns.heatmap(corr_matrix,
            annot=True,         # 숫자 표시
            fmt='.2f',          # 소수점 2자리
            cmap='RdYlGn',      # 빨강-노랑-초록
            center=0,           # 0을 중앙(노란색)으로
            linewidths=0.5)
plt.title('변수 간 상관관계')
plt.show()
📖
상관계수 읽는 법 (−1 ~ +1) • +1에 가까움 = 한 값이 커지면 다른 값도 같이 큼 (양의 상관)
• −1에 가까움 = 한 값이 커지면 다른 값은 작아짐 (음의 상관)
• 0에 가까움 = 거의 관계 없음
• 대각선은 항상 1.0 (자기 자신과의 상관) → 의미 없음, 무시
🎯
특히 "합격여부" 줄에 주목! 오늘 우리가 알고 싶은 건 "어떤 센서값이 합격여부에 영향을 주는가?"입니다. 히트맵에서 합격여부 행(또는 열)을 따라가며 색이 진한 칸을 찾으세요. 그게 합격 예측에 중요한 변수들입니다.
⚠️
상관관계 ≠ 인과관계 "같이 움직인다"는 사실이 "한쪽이 원인이다"라는 뜻은 아닙니다. 숨겨진 다른 요인 때문에 같이 변할 수도 있어요. 상관관계는 의심 가는 변수를 찾는 출발점일 뿐, 결론은 실험으로 확인해야 합니다.
